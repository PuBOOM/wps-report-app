# 文旅集团 — 数据查询汇总系统

> 基于 Streamlit 的 Web 应用，从 WPS 表单导出 CSV → 自动解析 → 按模板生成日报/周报/月报/年报。

---

## 1. 项目背景

### 1.1 数据来源

- **原始数据收集**：[WPS 表单](https://f.wps.cn/g/LE0ZQn2a/) —— 各项目人员每日填写游客量和收入
- **数据存储**：[金山文档在线表格](https://www.kdocs.cn/l/cvjtEa5rO4s3) —— 表单数据自动汇总

### 1.2 核心需求

1. **查询时间维度**：日、周、月、年、法定节假日
2. **项目灵活筛选**：可按板块、项目自由勾选，未选中不显示不汇总
3. **固定格式输出**：按日报/周报/月报/年报模板生成文字材料
4. **多端访问**：电脑浏览器 + 手机浏览器均可使用
5. **零成本**：Streamlit Cloud 免费部署，永久可用

## 4. 计算逻辑

### 4.1 项目总量

- **有子项目的项目**：`项目总量 = Σ(该项目所有子项目的游客量/收入)`
- **世纪之舟景区特殊规则**：
  - `世纪之舟（接待游客）` → 顶层餐厅·观光游客量
  - `世纪之舟（顶层餐厅）` → 顶层餐厅·消费游客量 + 餐厅收入
  - 两层数据合并为一行显示，均计入世纪之舟景区总量
- **无子项目的项目**：`项目总量 = Σ(该项目直接填报的所有数值)`

### 4.2 板块小计

```
板块小计游客量 = Σ(该板块内所有选中项目的总量游客量)
板块小计收入   = Σ(该板块内所有选中项目的总量收入)
```

### 4.3 总计

```
总游客量 = Σ(所有选中板块小计游客量)
总收入   = Σ(所有选中板块小计收入)
```

### 4.4 同比/环比

```
同比 = (本期值 - 去年同期值) / 去年同期值 × 100%    （保留两位小数）
环比 = (本期值 - 上一期值) / 上一期值 × 100%        （保留两位小数）
```

仅当去年同期/上一期有数据时显示，否则不显示该比较项。

### 4.5 单位切换

| 原始值范围 | 游客量单位 | 收入单位 |
|-----------|-----------|---------|
| `< 50` | `X人` | `X.XX元` |
| `≥ 50` | `X.XX万人次` | `X.XX万元` |

保留两位小数，四舍五入。

### 4.6 暂未营业判定

```
游客量 == 0 且 收入 == 0  →  显示"暂未营业。"
游客量 > 0 或 收入 > 0   →  正常显示数据
```

### 4.7 项目筛选规则

用户在侧边栏勾选的板块和项目决定报告内容：

- 未勾选的板块/项目 → 不在报告中出现
- 未勾选的板块/项目 → 不参与板块小计
- 未勾选的板块/项目 → 不参与总计汇总

### 4.8 数据重复检测

按 `(日期, 项目显示名, 子项目显示名)` 分组，出现 ≥2 条记录时，在报告顶部显示重复警告：

```
⚠️ ⚠️ ⚠️ 数据重复警告 ⚠️ ⚠️ ⚠️
以下项目在同一天存在多条数据，请检查后台：
  · 2025-12-21 【松江中路网红街区】江畔茶叙：4条重复
```

## 5. 名称映射机制

### 5.1 原则

- **输入端（WPS表单）名称保持不变**，不影响历史数据
- **输出端（报告）名称可随时修改**，通过 `config.py` 中的 `DISPLAY_SUB` 配置

### 5.2 当前映射

| 表单名称 (不可改) | 报告显示名 (可改) |
|-------------------|------------------|
| 松江中路 | 松江中路网红街区 |
| 世纪之舟 | 世纪之舟景区 |
| 北山公园 | 北山公园景区 |
| 江畔荷叶烘焙坊 | 江畔茶叙 |
| 广场集市 | 春启大东·好物甄选市集 |
| 世纪之舟（商业业态） | 商业业态 |

### 5.3 如何修改

编辑 `config.py` 中的 `DISPLAY_SUB` 和 `DISPLAY_PROJECT` 字典：

```python
DISPLAY_SUB = {
    "江畔荷叶烘焙坊": "江畔茶叙",      # 改成新名字
    "广场集市": "春启大东·好物甄选市集",
    # 添加新的映射...
}
```

修改后推送 GitHub，Streamlit Cloud 自动更新。

## 6. 使用方式

### 6.1 线上使用（推荐）

1. 打开浏览器访问部署地址
2. 左侧上传 WPS 导出的 CSV 文件
3. 选择报告类型（日报/周报/月报/年报）
4. 选择日期、板块、项目
5. 点击「生成报告」
6. 复制报告文本 → 粘贴使用

**电脑端和手机端浏览器均可访问**，手机端点左上角 `>` 展开侧边栏。

### 6.2 本地运行

```bash
# 安装依赖（仅首次）
pip install streamlit pandas openpyxl

# 启动
streamlit run app.py
```

或双击 `启动.bat`。

### 6.3 数据准备

WPS 在线表格 → 文件 → 导出 → 下载为 **CSV** 格式 → 上传到系统。

CSV 必须包含以下列：`日期`、`项目名称1~4`、`游客量1~4`、`收入1~4`。

## 7. 部署说明

### 7.1 Streamlit Cloud（当前方案）

1. 将代码推送到 GitHub 仓库
2. 打开 [share.streamlit.io](https://share.streamlit.io)
3. 关联 GitHub 仓库 → 选择 `app.py` → 部署
4. 获得永久公网 URL

**优点**：免费、自动 HTTPS、GitHub 推送自动更新、无需维护服务器。

### 7.2 更新线上版本

```bash
# 修改代码后
git add -A
git commit -m "更新说明"
git push origin master
```

Streamlit Cloud 检测到推送后自动重新部署（约 1-2 分钟）。

## 8. 维护指南

### 8.1 新增项目

编辑 `config.py` → `HIERARCHY` 字典，在对应板块下添加项目：

```python
"新项目名称": {
    "display": "新项目显示名",
    "has_sub": False,  # 无子项目
}
```

### 8.2 新增子项目

在项目配置的 `sub_projects` 列表中添加：

```python
"某个项目": {
    "display": "项目显示名",
    "has_sub": True,
    "sub_projects": [
        "原子项目1", "原子项目2", "新增子项目3",
    ],
}
```

### 8.3 修改显示名称

编辑 `DISPLAY_PROJECT` 或 `DISPLAY_SUB`，不影响历史数据。

### 8.4 调整单位阈值

编辑 `config.py` 中的 `SMALL_VALUE_THRESHOLD`（默认 50）。
